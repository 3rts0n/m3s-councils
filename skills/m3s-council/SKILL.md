# M3S Council

Read [the council method](references/COUNCIL.md) and use it on the user's decision. If the user only asks how the council works, explain it without running a council.

Give five seats the same brief: Counterparty, Contrarian, CFO, Operator, and Precedent. Use isolated first passes only when the platform supports them; otherwise disclose a single-model role pass. Use anonymous reviewers only when isolation and withholding authorship are real. In one conversation, call them non-anonymous review checks.

Preserve evidence, unknowns, and the strongest objection. Do not fabricate numbers or precedent. Produce the chairman's recommendation, what would change it, the smallest next test, and an owner and review date supplied by the user or clearly marked as proposed. The human owns the decision. Stop at the decision brief.
