# Sources and provenance

Prepared October 14, 2026 for Boot Room Labs, Middle 3rd Solutions.

## The method

The five standing seats and chairman structure come from M3S's earlier business council method. This edition makes execution mode and evidence limits explicit, preserves the strongest objection, and ends with a reviewable decision brief. It includes no private corpus, client records, access keys, or invented expert biographies.

The council pattern has many implementations. [Wade Foster's War Council in Zapier's public skills collection](https://github.com/zapier/wade-skills) is an acknowledged reference for the idea of opposing perspectives around a business decision. This package is a separate implementation, not an affiliated Zapier product. No Zapier source file or distinctive prompt passage is bundled here.

The method is an experiment, not an evaluation study. It does not claim to improve outcomes, eliminate sycophancy, or establish independent judgment merely by assigning several roles to a model.

## The connector

The connector supplies public instructions; the connected assistant performs the reasoning. It was implemented against the official Model Context Protocol specifications. No third-party server implementation is vendored in this package. Any runtime dependencies added to a hosted build retain their own licenses and must be recorded in its package manifest and lockfile.

- [MCP 2026-07-28 specification](https://modelcontextprotocol.io/specification/2026-07-28)
